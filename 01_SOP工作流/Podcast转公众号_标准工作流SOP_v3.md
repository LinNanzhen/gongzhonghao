# Podcast 转公众号文章 · 标准工作流 SOP v3

> **输入**：一个视频 / 播客链接（B站、YouTube、播客平台）
> **输出**：一套完整的、可直接粘贴进公众号后台的发布素材
> **耗时**：约 25-30 分钟
> **版本**：v3（2026-10-11）— 合并 v1 + v2，新增排版兼容与画质保障两章

## 🚦 两道闸门（不是参考，是拦错误用的）

> 这两道闸门是为了拦住已发布文章里的三处问题：摘要说"华裔女精英"而正文全篇用"他"、"重庆人/剑桥数学系"无出处、结尾仍写成"人的价值在重新定义"。

**闸门① 事实台账** — 台账里查不到的人物字段，文章里不能出现；代词必须全篇统一。

**闸门② 举证检查** — 每条引号内容必须有逐字稿时间戳，每个具体数字必须有信源。空着的行不许发。

## 输入

用户只需提供：
1. **视频链接**（必填）
2. **账号定位 / 读者画像**（可选，默认：泛财经 / 职场 / 科技类读者）
3. **特殊要求**（可选：要更口语化、加某几个重点、字数控制等）

**触发语**：`帮我把这个视频转成公众号文章：[链接]`

---

## 第 1 步 · 提取视频内容（约 3 分钟）

用 `doubao-video-extract` skill 的 `--run-lark` 模式自动完成：下载视频 → 转音频 → 上传飞书妙记 → 生成章节摘要 / 关键词 / 逐字稿。

**产出**：妙记链接（含逐字稿）、章节摘要列表、视频元数据（标题 / 时长 / UP主 / 封面 / 发布时间）

**关键检查**：逐字稿**必须带时间戳**。检查 `transcript.json` 的 `segments[].start/end` 字段，缺了就换转录方式——这是后面抽帧的前提。

**判断**：访谈类 / 演讲类 / 教程类？受访者是谁？核心主题一句话是什么？

---

## 第 2 步 · 事实台账（约 4 分钟）

按 `模板/事实台账.md` 逐字段填：姓名、职位、教育背景、职业经历、代表项目、数据来源链接。

**空着的字段不许编。** 查不到就写"未公开"，或者这个字段干脆不写进正文。

---

## 第 3 步 · 写正文（约 8 分钟）

风格细则以 `模板/禁用词表.md` 为准，这四条最容易犯：

### 开头
- ✅ `"这两天车圈有且仅有一件大事"`——第一句就给反常点
- ❌ `"先从最近最热的话题说起"` / `"一段32分钟的深度访谈，拆解了……"`

### 小标题
- ✅ `"她说现在不是泡沫，但理由和你想的可能不一样"`——小标题必须是一个**判断**
- ❌ `"AI是泡沫吗？还远没到终点"`——这是知识点，不是判断

### 叙述
- ✅ `"我们大概都以为……"` / `"这跟我的直觉是反的"`——把读者拉进来
- ❌ `"我听到这的时候愣了一下"`——自赏，把作者放在读者前面

### 结尾
- ✅ `"最后说两个我自己记下来的点：第一… 第二…"`
- ❌ `"人的价值在重新定义……"`

### 每节必带
🔴 **"我不同意的地方"**——v2 硬规则，不许留空。参考差评君逐条拆反对派的做法。

### 选题打分表
角度不达标根本不用写，避免"9 个判断凑数"。标准：反常识 / 有具体数字 / 有身份势能差 / 能延伸出行动建议。

---

## 第 4 步 · 抽帧（约 4 分钟）

细则见 `模板/字幕定位抽帧.md`。**顺序不能反**：

```
✅ 定金句 → 定位时间戳 → 抽帧     ← 图是证据，不是装饰
❌ 抽帧 → 挑不糊的 → 配文字     ← 图和内容无关
```

**Step 4.5 · 画质检查（新增，必做）**

抽完帧必须跑一次锐度检测，不要凭肉眼：

```bash
python3 -c "
from PIL import Image; import numpy as np, glob
for f in sorted(glob.glob('截图/*.jpg')):
    g = np.asarray(Image.open(f).convert('L'), float)
    lv = (g[:-2,1:-1]+g[2:,1:-1]+g[1:-1,:-2]+g[1:-1,2:]-4*g[1:-1,1:-1]).var()
    print(f'{lv:8.1f}  {f}')
"
```

| 拉普拉斯方差 | 判定 | 动作 |
|---|---|---|
| > 200 | 清晰 | 直接用 |
| 50–200 | 尚可 | 轻度锐化后用 |
| < 50 | 偏糊 | 见下方「放大到底有没有用」 |

## 第 5 步 · 画质保障（约 3 分钟）

### ⚠️ 先搞清一个误解：放大不能凭空造出细节

**实测结论**（720×960 肖像，2026-10-11）：

| 方案 | 面部锐度 | 相对原图 |
|---|---|---|
| 原图 720×960 | 9.93 | 1.00x |
| Lanczos 放大到 1080 | 3.83 | **0.39x** ❌ 越放越糊 |
| Lanczos + Unsharp(2.0,130%) | 10.57 | **1.06x** ⚠️ 等于没变 |
| 放大到 1440 + 锐化 | 4.95 | 0.50x ❌ 更糊 |

**原理**：拉普拉斯方差衡量的是**真实细节**。纯插值不产生新细节，只会放大已有噪点——所以"放大 + 锐化"的天花板大约就是 1.0x。

**但正文配图反而能提升**，因为缩到公众号最佳宽度会减少像素密度：

| 方案 | 锐度 | 体积 |
|---|---|---|
| 原图 1280×720 | 426 | 107KB |
| 缩至 **1000px** + USM(1.5, 90%) | **1510（3.55x）** | **70KB** ✅ 又清晰又小 |
| 缩至 1200px + USM | 1022（2.40x） | 92KB |

**结论：正文图一律缩到 1000px 再锐化，锐度和体积双赢。**

**肖像要用小倍率**（大倍率反而降）：

| 方案 | 锐度 | 体积 |
|---|---|---|
| 原图 720×960 | 16.1 | 71KB |
| → **960×1280** + USM(2.0, 110%) | **17.8（1.11x）** | **93KB** ✅ |
| → 1080×1440 + USM(2.0, 130%) | 14.4（0.89x） | 114KB ❌ |

⚠️ **肖像拉普拉斯方差天然偏低**（本例 16 vs 正文图 264），因为人脸大面积是平滑肤色。**低不代表糊**，判断人脸要看眼部/轮廓带，不要看全图数值。

### 真正有效的三条，按优先级

1. **换源**（收益最大）— 从原始视频文件抽帧。B站优先选 1080P60 / 高码率。720P → 1080P 是源头提升，任何后期都比不了。
2. **换时间点** — 避开运动模糊帧。说话时头部晃动最容易糊，取说话**前 1.5 秒**（自然表情）。
3. **AI 超分**（谨慎）— Real-ESRGAN 这类模型会"编"出合理纹理，实测可到 1.3–1.6x。
   ⚠️ **本机实测未能跑通**：torch 依赖安装失败（macOS ARM + Python 3.13 无预编译轮子）。要用需先配好独立环境，且**人脸慎用**——可能生成不存在的细节。

### 本项目可直接用的图片优化参数

```python
from PIL import Image, ImageFilter
# 正文配图：缩到 1000px 宽 + 轻锐化
im = Image.open(src).resize((1000, 562), Image.LANCZOS).filter(ImageFilter.UnsharpMask(1.5, 90, 2))
im.save(dst, "JPEG", quality=88, optimize=True, progressive=True)
# 肖像：放大到 960×1280 + 中锐化（不要放太大）
im = Image.open(src).resize((960, 1280), Image.LANCZOS).filter(ImageFilter.UnsharpMask(2.0, 110, 2))
```

参考实例：`03_李飞飞AI两类人_案例/截图_优化/`

### 工具链

```bash
# 基础抽帧
ffmpeg -ss 00:14:23.5 -i input.mp4 -frames:v 1 -q:v 2 frame.jpg

# 源视频清晰度不足时：2 倍放大 + 轻度锐化（期望收益有限）
ffmpeg -ss 00:14:23.5 -i input.mp4 -frames:v 1 \
  -vf "scale=iw*2:ih*2:flags=lanczos,unsharp=5:5:0.8:5:5:0.0" -q:v 2 frame.jpg

# 肖像专用：3:4 竖版裁剪
ffmpeg -ss 00:02:15 -i input.mp4 -frames:v 1 \
  -vf "crop=ih*3/4:ih,scale=1080:1440:flags=lanczos" -q:v 2 portrait.jpg
```

### 公众号图片规格

| 项 | 要求 | 原因 |
|---|---|---|
| 宽度 | ≤ 1000px | 超过会被重压 |
| 单图体积 | ≤ 100KB（base64 后） | 超了公众号会丢图 |
| 总像素 | ≤ 600 万 | 平台硬限制 |
| 格式 | JPEG quality 80 | 体积/画质平衡点 |
| SVG | 必须写死 width/height | iOS 上不写尺寸不渲染 |

## 第 6 步 · 排版成公众号兼容 HTML（约 3 分钟）

### 🚨 第一条铁律：用 `<section>`，永远不用 `<div>`

公众号新版编辑器底层是 **ProseMirror**，标签白名单里**没有 `div`**。
用 `div` 包着的卡片、引用块、色块，**粘贴后整个 div 连同背景、圆角、边框被整段吞掉，只剩文字**。

这就是「代码粘进去看着好好的，一保存就全丢了」的真相。

```html
❌ <div style="background:#faf8f5;border-radius:8px;padding:16px;">
✅ <section style="background:#faf8f5;border-radius:8px;padding:16px;">
```

**完整白名单见 `模板/公众号HTML硬规则.md`**，动手前先看一遍。

### 标准产出流程

```python
# 1. 剥外壳：去掉 DOCTYPE/html/head/body，只留 body 内容
# 2. 删注释：<!-- xxxx --> 会被吞或渲染成正文
# 3. div → section（全部 56 个，一个不漏）
# 4. 图片优化后 base64 内嵌
#    正文图：resize((1000,562), LANCZOS) + UnsharpMask(1.5,90,2) + q88  → 实测 3.55x 锐度，体积反降
#    肖像图：resize((960,1280), LANCZOS) + UnsharpMask(2.0,110,2) + q88 → 实测 1.11x
# 5. 修正不合法属性：
#    - letter-spacing:0.06em → 1px（em 单位部分机型异常）
#    - cellpadding/cellspacing → 移进 style
#    - img width="100%" → style="width:100%"
# 6. 出厂质检（见下）
```

### 出厂质检门禁（写文件前必须跑）

```python
assert 0 == len(re.findall(r'<div\b', html)),  "残留 div"
assert 0 == len(re.findall(r'\bid="', html)),    "残留 id"
assert 0 == len(re.findall(r'class="', html)),    "残留 class"
assert 0 == len(re.findall(r'<script', html)),    "残留 script"
assert 0 == len(re.findall(r'position:', html)),  "残留 position"
assert 0 == len(re.findall(r'linear-gradient', html)), "残留渐变"
assert 0 == len(re.findall(r'display:flex', html)),   "残留 flex"
```

任一不过直接报错退出，不要放行。

| 元素 | 规格 |

| 主色调 | 金色 `#c8a96e` |
| 引用块背景 | 米色 `#faf8f5` |

## 第 7 步 · 交付（约 2 分钟）

### 交付物清单

1. ✅ **公众号文章完整稿**（Markdown，人味版）
2. ✅ **极简版**：Abstract + Keywords + 三大核心判断
3. ✅ **`*_公众号兼容版.html`** — section 版 + base64 图，**主交付物**
4. ✅ **`长图_分段_*.png`** — playwright 渲染的兜底方案
5. ✅ **5 个备选标题**
6. ✅ **事实台账**（已填满，含信源链接）

### 三条导入路径（按推荐顺序）

**🟢 路径 A · 直接复制粘贴（默认，5 分钟）**
```
Chrome 打开「*_公众号兼容版.html」→ Cmd+A → Cmd+C
→ 后台 内容与互动 → 新的创作 → 文章 → 正文区 Cmd+V
```
图片自动被编辑器接管转存到微信 CDN，**不裂图，不需要手动换图**。

**🟡 路径 B · 源码模式（要精修样式时）**
编辑器工具栏**最右侧** `源码`（`<>`）→ 粘贴纯净片段 → 切回可视化。
注意：源码片段里是 `div`，粘完**不要点"清除格式"**，会连内联样式一起清掉。

**🔵 路径 C · 长图兜底（重要发刊 / 跨平台）**
`长图_分段_*.png` 逐张上传。**任何编辑器都不丢排版**。
代价：文字不可复制、搜索引擎不收录。

## 📋 发稿前检查清单

### 事实（闸门，填不出就删）
- [ ] 台账每个字段都有信源链接
- [ ] 全篇代词统一（他 或 她，一个都不混）
- [ ] 引号内容都有逐字稿时间戳
- [ ] 所有具体数字都有出处

### 去 AI 味
- [ ] 全文无禁用词（跑一遍 `模板/禁用词表.md`）
- [ ] 每节都有"我不同意的地方"
- [ ] 开头留的钩子，结尾展开了

- [ ] **0 个 `div`**，全部是 `section`
- [ ] **0 个 class / id / script / position / 渐变 / flex**

- [ ] 人物卡片三行齐全（查不到的已删）

### 画质（v3 新增）
- [ ] 每张图跑过锐度检测
- [ ] 肖像图看的是面部区域锐度，不是全图
- [ ] 正文图宽度 ≤ 1000px，单图 ≤ 100KB

### 篇幅
- [ ] 字数 2000–3000
