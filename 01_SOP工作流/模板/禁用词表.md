# 禁用词表

写完正文后，对照本表逐条查一遍。命中的词**替换或删除**，只改一次，��通全文。

---

## 一、高危词（财经稿 AI 味重灾区）

这些词一出现，读者立刻判断"这是 AI 写的"。

| 禁用词 | 替换方向 |
|---|---|
| 赋能 | 直接说"给了谁什么能力" |
| 抓手 | 说具体动作 |
| 闭环 | 说"从…到…是一套流程" |
| 打法 | 说具体策略 |
| 底层逻辑 | 删掉，直接说因果 |
| 颗粒度 | 说"细到什么程度" |
| 拉齐 / 对齐 | 说"统一"或直接说动作 |
| 复盘 | 说"事后看" |
| 沉淀 | 说"攒下来" |
| 链路 | 说"流程" |
| 心智 | 删掉 |
| 势能 | 说"势头" |
| 破局 | 说具体动作 |

## 二、句式黑名单

| ❌ 禁用 | ✅ 替代 |
|---|---|
| 首先 / 其次 / 最后 | 直接说，不排��� |
| 值得注意的是 | 删掉，直接说 |
| 不可忽视的是 | 删掉 |
| 在……的今天 | 删掉 |
| 这背后是一个重要的…… | 说清"重要在哪" |
| 不仅仅是……更是…… | 拆成两句 |
| 总而言之 | 删掉 |
| 让我们一起 | 删掉 |
| 值得深思的是 | 删掉 |
| 无疑 / 显然 | 给出理由，让读者自己判断 |
| 综合来看 | 删掉 |

---

## 三、结构黑名单

| ❌ 禁用 | 原因 |
|---|---|
| "人的价值在重新定义" | 典型 AI 升华句 |
| "这说明了……" | 观点说完就完，不要替读者下结论 |
| "在这个信息爆炸的时代" | 空转开场 |
| "随着……的不断发展" | 同上 |
| 每节都是"她说X → 我认同 → 补充" | 缺立场 |

## 四、称呼黑名单

| ❌ 禁用 | ✅ 替代 |
|---|---|
| 管什么 / 什么资历 / 凭什么听 | 教育经历 / 工作经历 / 代表项目 |
| XX大师 / XX教父 | 职位全称 |
| XX协会会员、XX奖获得者 | 一律删（头衔越多可信度越低） |

## 五、自检命令

写完存成 txt 后跑一遍，列出所有命中位置：

```bash
grep -n -E "赋能|抓手|闭环|打法|底层逻辑|颗粒度|对齐|复盘|沉淀|链路|心智|首先|其次|值得注意的是|不可忽视|总而言之|在.*的今天|这背后是|不是.*而是|不仅是|让我们" 文章.txt
```

逐条处理，不要只改第一处。
