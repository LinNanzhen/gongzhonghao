> **输入**
>
> ：一个采访素材（视频 / 播客链接、访谈录音、逐字稿）+ 采访对象身份

>
> ：一套可直接发布的深度报道（人味稿 + 公众号兼容 HTML + 参考文献 + 事实台账）

>
> ：约 60-90 分钟（含行业洞察研究）
> **版本**

## 🚦 三道闸门（不是参考，是拦错误用的）

> 前两道继承 v3，是踩坑固化的；第三道是深度报道新增的，专门拦 "行业判断没出处"。

**闸门① 事实台账** — 台账里查不到的人物字段，文章里不能出现；代词必须全篇统一。

**闸门② 举证检查** — 每条引号内容必须有逐字稿时间戳 / 原文出处，每个具体数字必须有信源。空着的行不许发。

**闸门③ 行业判断可追溯（新增）** — 行业洞察章节里的每个趋势判断、对比结论、行业数据，必须有出处（媒体 / 报告 / 官方统计），或者是明确标注的 "作者判断"。参考文献表填不满不许发。

## 输入

用户只需提供：



1. **采访素材**（必填）：视频 / 播客链接、或访谈录音文件、或已有逐字稿

2. **采访对象**（必填）：姓名 + 身份（职位 / 机构）

3. **账号定位 / 读者画像**（可选，默认：泛财经 / 科技 / 职场读者）

4. **特殊要求**（可选：不要行业洞察、配色换红、字数控制等）

**触发语**：`帮我把这个人物专访做成深度报道：[素材]`



***

## 第 0 步・选题评估（约 3 分钟，新增）

动笔前先按 Z Finance 式四问打分，**至少 2 个强命中才写**，否则降级为普通访谈稿或放弃：



| # | 评估维度         | 问题               | 强命中示例                            |
| - | ------------ | ---------------- | -------------------------------- |
| 1 | **身份势能差**    | 受访者身份有没有反常识落差？   | 执掌字节 AI 数据底座的人，上一站是 TikTok 直播操盘手 |
| 2 | **行业洞察点**    | 这段访谈能否带出一个行业级判断？ | 数据从 "天然矿藏" 变成 "工业品"，行业进入消耗战      |
| 3 | **反常识 / 反差** | 有没有与主流认知相悖的观点？   | 同行把数据权杖交给科学家，字节偏交给业务战将           |
| 4 | **可延伸性**     | 能延伸出读者可用的行动建议吗？  | "与其纠结 10 分钟里能否被选中，不如先攒那一万小时"     |

**不写的信号**：纯个人励志故事无行业信息、观点全是正确的废话、无法核验身份。



***

## 第 1 步・素材获取与逐字稿（约 5 分钟）



* **视频 / 播客**：用 `doubao-video-extract` skill 的 `--run-lark` 模式 → 妙记逐字稿（**必须带时间戳**，这是后面抽帧和举证的前提）

* **录音文件**：上传飞书妙记转写，同样确认时间戳完整

* **已有逐字稿**：直接使用，人工确认时间戳 / 原话完整性

* **公开资料搜集（新增）**：人物官方 bio、代表作品、机构背景、近期行业报道 —— 为第 2、3 步做素材准备

**判断**：访谈类型（人物经历型 / 观点输出型 / 行业分析型）？核心主题一句话是什么？行业背景是什么？



***

## 第 2 步・事实台账（约 5 分钟，继承 + 升级）

按 `模板/事实台账.md` 逐字段填（姓名、职位、教育经历、工作经历、代表项目、核心观点），**新增两节**：



* **行业数据表**：访谈中出现的行业规模、增长率、竞对数据，逐条记来源

* **外部佐证表**：人物的关键论断，找公开报道 / 数据佐证或证伪（佐证不上的降级为 "作者转述"）

**空着的字段不许编。** 查不到就写 "未公开"，或者这个字段干脆不写进正文。



***

## 第 3 步・行业洞察研究（约 15 分钟，新增）

这是深度报道区别于转写稿的核心步骤。参考 Z Finance《王赢磊》的做法，产出一份 300-500 字的行业洞察笔记：



1. **行业坐标系**：受访者所在行业的当前格局（头部玩家、竞争态势、所处阶段）

2. **关键数据**：行业规模 / 增长率 / 关键指标（如 "Meta 143 亿美元入股 Scale AI"" 字节 5 万亿参数大模型 "）

3. **对照样本**：同类人物 / 公司的不同做法（如 Z Finance 对照 DeepSeek、腾讯、阿里）

4. **冲突点**：行业争议、受访者立场的对立面、利益相关者的不同声音

5. **作者独立判断**：这个行业故事里，最重要的是什么？（必须想清楚，结尾要用）

**产出**：行业洞察笔记（要点 + 数据 + 来源链接），它是正文行业章节和结尾判断的素材库。**每条数据必须带来源**—— 这就是闸门③ 的源头。



***

## 第 4 步・写正文（约 20 分钟）

### 深度报道结构（Z Finance 式章节化）



```
标题：系列前缀｜人物 + 动词 + 核心成就/事件
     （例：Z Waves｜90后王赢磊，四年打穿TikTok全球直播，转身执掌字节AI数据底座）
导语：开篇直接抛核心事件/反差，加粗关键主体（2-3 段，不铺垫）
章节 1：起点 / 背景——人物如何走到今天
章节 2：核心事件 / 成就——访谈最精彩的部分（占最大篇幅）
章节 3：转折 / 冲突——行业洞察 + 对照样本
章节 4：为什么是他/她——作者的判断与行业逻辑闭环
结尾：不升华，收在具体判断 + 可行动建议
```

### 写作细则

**继承 v3（不改）**：



* 开头第一句就给反常点（✅"这两天车圈有且仅有一件大事"；❌"先从最近最热的话题说起"）

* 小标题必须是一个**判断**，不是知识点（✅"她说现在不是泡沫，但理由和你想的可能不一样"；❌"AI 是泡沫吗？"）

* 每节必带「我不同意的地方」—— 深度报道升级为「深度异议」：你的疑问 / 反面证据 / 这个判断的适用边界，不许留空

* 用 "我们 / 大伙 / 咱" 拉读者入伙，不用 "我听到这的时候愣了一下" 式自赏

* 结尾收在具体判断（✅"最后说两个我自己记下来的点：第一… 第二…"；❌"人的价值在重新定义"）

* 跑一遍 `模板/禁用词表.md`

**新增（Z Finance 式）**：



* **加粗只用于三类**：人名 / 机构、关键数字、核心结论 —— 全篇统一，绝不多用

* 关键论断尽量用引号原话（后面接出处标注，如 "—— 截自原视频 01:04"）

* 行业章节的每个判断要有数据或对照支撑

* **事实与判断分离**：事实给来源，判断明说 "这是作者的看法"



***

## 第 5 步・抽帧与配图（约 5 分钟，继承 v3）

完整继承 v3 第 4/5 步的规则，**顺序不能反**：



```
✅ 定金句 → 定位时间戳 → 抽帧     ← 图是证据，不是装饰
❌ 抽帧 → 挑不糊的 → 配文字     ← 图和内容无关
```



* 抽完帧必须跑拉普拉斯方差锐度检测（>200 清晰 / 50-200 尚可 / <50 偏糊）

* 正文图缩到 **1000px** + 轻锐化（`UnsharpMask(1.5, 90, 2)`），锐度和体积双赢

* 肖像放大到 **960×1280** + 中锐化（`UnsharpMask(2.0, 110, 2)`），看眼部 / 轮廓带，不看全图数值

* 图片规格：宽 ≤ 1000px、单图 ≤ 100KB（base64 后）、JPEG quality 80、总像素 ≤ 600 万

**新增：无视频素材时的配图方案**



* 人物公开照片（必须标来源，写入图注 "图源：XXX"）

* 行业数据图表（自制图表，标注数据来源）

* 场景示意图（**禁 AI 生成冒充真实照片**，AI 生成图必须单独标注）



***

## 第 6 步・深度特稿排版（约 10 分钟，新增版式）

### 排版结构（学 Z Finance，落到你们的技术栈）



```
[品牌头图]——固定视觉，每期复用（沿用现有）
[标题]——系列前缀｜主标题，16-18px 加粗
[作者信息]——原创 公众号名 · 日期 · 城市（灰色小字）
[导语]——正文样式，关键主体加粗
[章节小标题]——「关键词：内容」加粗，左侧 3px 主色竖线
[正文]——15px，行高 1.8，段间空行
[配图+图注]——12px 灰色斜体，格式「说明。图源：XXX」
[参考文献]——12px 灰色，编号列表（见第 7 步）
[系列导航]——文末固定两行：「系列 · 目录」+ 上一篇链接
```

### 排版规格



| 元素        | 规格                                           |
| --------- | -------------------------------------------- |
| 主色调       | 品牌金 `#c8a96e`（沿用）／财经红 `#a4122f`（可切换，二选一全篇统一） |
| 章节小标题     | 左侧 3px 主色竖线 + 16px 加粗，格式「关键词：内容」             |
| 正文字号 / 行高 | 15px / 1.8                                   |
| 强调        | **只加粗人名、数字、结论**，全文统一                         |
| 引用块       | 米色 `#faf8f5` 背景 + 左侧主色边线                     |
| 图注        | 12px 灰色斜体，格式「说明。图源：XXX」                      |
| 参考文献      | 12px 灰色，编号 + 媒体名：《标题》，日期，URL                 |
| 系列导航      | 文末固定两行，引导连续阅读                                |

### 技术硬规则（继承 v3，一条不能破）



* 容器用 `<section>`，**永远不用&#x20;**`<div>`（ProseMirror 白名单没有 div，用了整段被吞）

* 0 个 class / 0 个 id / 0 个 script / 0 个 position / 0 渐变 / 0 flex

* 图片 base64 内嵌或 mmbiz 链接，本地路径 100% 裂图

* SVG 必须写死 width/height（iOS 不写不渲染）

* 完整白名单见 `模板/公众号HTML硬规则.md`，动手前先看一遍

### 出厂质检门禁（写文件前必须跑）



```
assert 0 == len(re.findall(r'<div\b', html)),  "残留 div"
assert 0 == len(re.findall(r'\bid="', html)),    "残留 id"
assert 0 == len(re.findall(r'class="', html)),    "残留 class"
assert 0 == len(re.findall(r'<script', html)),    "残留 script"
assert 0 == len(re.findall(r'position:', html)),  "残留 position"
assert 0 == len(re.findall(r'linear-gradient', html)), "残留渐变"
assert 0 == len(re.findall(r'display:flex', html)),   "残留 flex"
assert 0 == len(re.findall(r'REPLACE_IMG_', html)),   "未换图占位符"
```

任一不过直接报错退出，不要放行。

## 第 7 步・参考文献（约 3 分钟，新增）

按 `模板/参考文献模板.md`（新增待建）填写，覆盖四类：



1. **人物身份来源**：官方 bio / 权威媒体报道

2. **关键事实引用**：访谈论断对应的公开报道 / 数据

3. **行业数据来源**：报告 / 新闻 / 官方统计

4. **格式统一**：`编号. 媒体名：《标题》，日期，URL`

**闸门③ 检查**：正文里每个行业判断、每个关键数字、每个人物身份，都能在参考文献表里找到对应条目。

> 参考格式（Z Finance 原文 36 条参考文献的写法）：
> `1. 36 氪《智能涌现》：《继 Seed、Flow 后，字节又成立一个 AI 一级部门，直指「数据」》，2026-08-11，https://m.36kr.com/…`



***

## 第 8 步・交付（约 3 分钟，继承 + 升级）

### 交付物清单



1. ✅ **深度报道完整稿**（Markdown，人味版）

2. ✅ **极简版**：Abstract + Keywords + 三大核心判断 + 行业洞察要点

3. ✅ `*_公众号兼容版.html` — section 版 + base64 图，**主交付物**

4. ✅ `长图_分段_*.png` — playwright 渲染的兜底方案

5. ✅ **5 个备选标题**（覆盖反常识型 / 身份型 / 数字型 / 行动型 / 悬念型）

6. ✅ **事实台账**（已填满，含信源链接）

7. ✅ **参考文献表**（新增，闸门③）

### 三条导入路径（按推荐顺序）

**🟢 路径 A・直接复制粘贴（默认，5 分钟）**



```
Chrome 打开「*_公众号兼容版.html」→ Cmd+A → Cmd+C
→ 后台 内容与互动 → 新的创作 → 文章 → 正文区 Cmd+V
```

图片自动被编辑器接管转存到微信 CDN，不裂图，不需要手动换图。

**🟡 路径 B・源码模式（要精修样式时）**

编辑器工具栏**最右侧** `源码`（`<>`）→ 粘贴纯净片段 → 切回可视化。

注意：粘完**不要点 "清除格式"**，会连内联样式一起清掉。

**🔵 路径 C・长图兜底（重要发刊 / 跨平台）**

`长图_分段_*.png` 逐张上传。任何编辑器都不丢排版。

代价：文字不可复制、搜索引擎不收录。
