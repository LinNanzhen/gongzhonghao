## 🚦 v3 的三道硬规则

> 这三条是 v3 相对 v2 最重要的补充，都是踩过坑固化的。

**① 容器用 `<section>`，永远不用 `<div>`** — 公众号编辑器底层 ProseMirror 白名单里没有 div，用 div 包着的卡片/引用块/色块会被**整段吞掉**，只剩文字。详见 [`模板/公众号HTML硬规则.md`](01_SOP工作流/模板/公众号HTML硬规则.md)。

**② 抽帧图必测锐度** — 拉普拉斯方差 < 50 判定偏糊。放大不能凭空造细节（实测天花板约 1.0x），真正有效的是换源视频、换时间点、AI 超分。

**③ 交付前跑质检门禁** — 0 div / 0 class / 0 id / 0 script / 0 position / 0 渐变 / 0 flex，任一不过不放行。

## 🚀 怎么用

> **"帮我把这个视频转成公众号文章：[链接]"**

按 v2 SOP 跑全套，约 20-25 分钟，交付：

1. **人味版完整文章**
2. **极简版摘要**（Keywords标题、Abstract、三大核心判断）
3. **可直接导入的HTML**（含人物卡片，壹伴一键复制）
4. **3-4张字幕定位抽帧图**（每张精确对应文中金句）
5. **5个备选标题**
6. **已填满的事实台账 + 举证表**

## 🔴 v2 的两道闸门

这两条是 v2 相对 v1 最重要的改动，**不是参考，是拦错误用的**：

**闸门① 事实台账** — 台账里查不到的人物字段，文章里不能出现；代词必须全篇统一。

**闸门② 举证检查** — 每条引号内容必须有逐字稿时间戳，每个具体数字必须有信源。空着的行不许发。

> 这两道闸门是为了拦住已发布文章里的三处问题：摘要说"华裔女精英"而正文全篇用"他"、"重庆人/剑桥数学系"无出处、结尾仍写成"人的价值在重新定义"。

## ✍️ 写作风格规范（v2）

风格细则以 [`模板/禁用词表.md`](01_SOP工作流/模板/禁用词表.md) 为准，以下是四条最容易犯的：

### 开头
✅ 要："这两天车圈有且仅有一件大事"——第一句就给反常点
❌ 不要："先从最近最热的话题说起" / "一场32分钟的深度访谈，拆解了……"

### 小标题
✅ 要："她说现在不是泡沫，但理由和你想的可能不一样"——把标题当成一个有信息量的判断
❌ 不要："AI是泡沫吗？还远没到终局"——那是知识点，不是判断

### 叙述
✅ 要："我们大概都以为……" / "这跟我的直觉是反的"——用"我们/大伙/咱"拉读者入伙
❌ 不要："我听到这的时候愣了一下"——这是自赏，把作者放在读者前面

### 结尾
✅ 要："最后说两个我自己记下来的点：第一…… 第二……"
❌ 不要："人的价值在重新定义……"

### 每节必带
🔴 **"我不同意的地方"**——v2 新增硬规则，不许留空。参考差评君逐条拆反对派的做法。

## 📌 发稿前检查清单

**事实（闸门，填不出就删）**
- [ ] 台账每个字段都有信源链接
- [ ] 全篇代词统一（他 或 她，一个都不混）
- [ ] 引号内容都有逐字稿时间戳
- [ ] 所有具体数字都有出处

**去 AI 味**
- [ ] 全文无禁用词（跑一遍 `模板/禁用词表.md` 里的 grep）
- [ ] 每节都有"我不同意的地方"
- [ ] 开头留的钩子，结尾展开了

**排版**
- [ ] 人物卡片三行齐全（查不到的已删）
- [ ] 每张图标注"截自原视频 + 时间点"
- [ ] 字数 2000-3000
