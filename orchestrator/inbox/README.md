# inbox · 手动投递

把一条素材丢进这个目录，下一次 `tick` 就会为它建任务。

## 格式

**方式一：`.md` / `.txt`**（最简单）

```
https://www.youtube.com/watch?v=xxxxxxxxxxx
备注写这里，可以多行
```

- 第一处出现的链接就是素材地址；
- 链接之前的非空行当作标题；
- 链接之后的行当作备注。

**方式二：`.json`**（需要结构化时）

```json
{"url": "https://...", "title": "某人对谈", "channel": "Bloomberg", "notes": "重点看第 12 分钟"}
```

## 规则

- 幂等：同一链接重复投递只保留一个 run（`run_id = sha1(规范化链接)[:12]`）。
- 投递后文件**不会**被自动删除，方便回看；要重跑请先删掉 `orchestrator/runs/{run_id}/`。
- 不要放二进制文件（音频/视频请放进对应案例的 `转写/` 或根目录 `_原始素材/`）。
