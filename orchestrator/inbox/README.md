# inbox · 手动投递

把素材丢进这个目录，下一次 `tick` 就为它建任务。**转写稿也放这里**，不用管案例目录。

## 三种投法

**① 只有链接**

```
001-马斯克.md
    https://www.youtube.com/watch?v=xxxx
    备注：重点看第 12 分钟
```

**② 链接 + 转写稿（推荐）**

```
David_Baker.md      ← 第一行标题，第二行链接
David_Baker.srt     ← 同名文件就是它的转写
```

`tick` 建任务时会把同名的 `.srt` / `.vtt` / `.json` / `.txt` 一起复制进
`cases/NN_某案例/转写/`，然后自动转成 `transcript.json`。**不需要先建任务再放文件。**

**③ 只有转写稿（本地录音）**

```
本地录音.srt
```

没有链接也能建任务，文件名就是标题，`source.kind` 记为 `local`。

## 规则

- 配对靠**文件名相同**（`X.md` ↔ `X.srt`）；扩展名区分主文件与附件。
- 幂等：同一链接重复投递只保留一个 run（`run_id = sha1(规范化链接)[:12]`）；
  本地素材按文件名哈希。
- 投递文件不会被自动删除，方便回看；要重跑先删 `orchestrator/runs/{run_id}/`。
- 不要放音频/视频二进制，那些进案例的 `音频/` 或根目录 `_原始素材/`。
